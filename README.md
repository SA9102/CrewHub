# CrewHub

This is a simple application that will allow small teams to:

- communicate
- organise members into teams
- schedule and manage events
- track basic team activity

This project is being built for a personal portfolio to demonstrate full-stack development skills, including testing, authentication, and API handling.

## Tech Stack

- React
- Next.js
- TypeScript
- Neon (Postgres database)
- Prisma (ORM)
- shadcn (component library)

## Main Utility Libraries

- Auth.js (credential authentication)
- Vitest (test suite, very similar to Jest)
- Resend (send emails)

## Concepts learned:

- Client and server components, and when to use one over the other
- Using Vitest for integration testing - testing API routes
